# Пауза — что делать с этой папкой

## Шаг 1. Постоянный хостинг (вместо временной ссылки netlify.app)

Раньше ссылка была временной — поэтому у друзей не открывалось.
Теперь размещаем на GitHub Pages — это бесплатно и **не истекает**.

1. Зайдите на https://github.com и создайте бесплатный аккаунт (если его нет).
2. Нажмите зелёную кнопку **New** (создать репозиторий).
   - Имя репозитория: `pauza-app`
   - Отметьте **Public**
   - Нажмите **Create repository**
3. На странице репозитория нажмите **uploading an existing file**
   (или «Add file» → «Upload files»).
4. Перетащите туда ВСЕ файлы из этой папки (index.html, style.css,
   app.js, content.js, manifest.json, sw.js, папку icons) — кроме
   этого README и папки `.well-known`, если она есть, её тоже добавьте.
5. Нажмите **Commit changes**.
6. Зайдите в **Settings** репозитория → слева **Pages**.
7. В разделе «Branch» выберите `main` и папку `/ (root)` → **Save**.
8. Через 1–2 минуты GitHub покажет вашу постоянную ссылку вида:
   `https://ВАШ_НИК.github.io/pauza-app/`

Эта ссылка уже не исчезнет. Отправляйте её друзьям — и просите
открывать именно в Chrome, не во встроенном браузере мессенджера.

## Шаг 2. Настоящий .apk-файл (чтобы просто скидывать файл)

Когда ссылка из шага 1 у вас есть и открывается — see APK_PLAN.md
в этой же папке: там пошагово, как за 10 минут на сайте
pwabuilder.com получить готовый .apk без Android Studio и без кода.
